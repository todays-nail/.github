# 오늘 네일

손 사진과 AI를 활용해, 나에게 어울리는 네일 스타일을 더 빠르게 찾는 서비스입니다.  
시술 전에 여러 디자인을 비교해 보고, 마음에 드는 결과를 저장해 취향을 정리할 수 있습니다.

## 서비스 소개

오늘 네일은 "어떤 네일이 어울릴지" 고민하는 시간을 줄이는 데 집중합니다.  
손 사진과 원하는 디자인 이미지를 바탕으로 AI 피팅 결과를 만들고, 결과를 모아 비교하며 선택할 수 있습니다.

## 고객이 할 수 있는 것

- Apple, Google, Kakao로 간편하게 로그인
- 프로필과 선호 스타일을 설정해 개인화된 시작
- 손 사진 + 디자인 이미지 업로드 후 AI 네일 피팅 생성
- 생성된 결과를 목록/상세로 비교하고, 마음에 드는 스타일 저장
- 결과 좋아요/삭제로 내 취향 컬렉션 정리
- 설정에서 AI 데이터 전송 동의 관리, 고객지원/약관 확인
