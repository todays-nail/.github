# Today's Nail

Today's Nail은 고객과 네일샵을 더 빠르게 연결하는 뷰티 예약 서비스입니다.
원하는 네일 디자인 탐색부터 견적 요청, 예약, 방문 관리까지 한 흐름으로 제공합니다.

## 서비스 소개

- 고객은 취향에 맞는 디자인을 탐색하고, 원하는 조건으로 네일샵을 찾을 수 있습니다.
- 네일샵은 예약과 고객 요청을 효율적으로 관리하고 운영 생산성을 높일 수 있습니다.
- 예약 전 탐색 경험과 예약 후 방문 경험을 끊김 없이 연결하는 것을 목표로 합니다.

## 우리의 방향

- 빠른 실험과 사용자 피드백 기반 개선
- 예약 성공률과 재방문율을 높이는 UX 집중
- 현장 운영에 바로 도움이 되는 기능 우선 개발
